# Clearline – downloads

Ready-to-run versions of Clearline for **Windows**, **macOS** (Apple silicon)
and **Linux**. Get the newest one under
[Releases](https://github.com/CrissZollo/clearline-releases/releases/latest).

* **Windows:** download `clearline-windows-x86_64.zip`, unzip, run `clearline.exe`.
* **macOS:** download `clearline-macos-arm64.zip`, unzip, right-click
  *Clearline.app* → *Open* the first time.
* **Linux:** download `clearline-linux-x86_64.tar.gz`, extract, run `./clearline`.

Once installed, Clearline updates itself: it shows **Update now** when a new
version is ready.

This repository only holds the downloads; they are published automatically.
